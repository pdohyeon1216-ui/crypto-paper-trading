기존 버전에서 이미 한 종목에 롱·숏이 함께 생성된 경우에는 임의 청산하지 않습니다. 한쪽을 전량 청산할 때까지 신규·추가 진입이 제한됩니다.

1. 포지션 진입

  1. 상단에서 거래할 종목을 선택합니다.
  2. 사용 증거금과 레버리지를 입력합니다.
  3. 롱 진입 또는 숏 진입을 누르면 시장가로 진입합니다.
  4. 예약 진입은 방향 버튼을 누른 뒤 차트에서 지정가를 선택합니다.

보유 포지션과 같은 방향은 추가 진입으로 합산되며 평균 진입가와 유효 레버리지가 다시 계산됩니다. 반대 방향 버튼과 예약 주문은 차단됩니다.

2. 격리 증거금과 손익

  • 각 포지션의 사용 증거금과 청산가는 해당 포지션 기준으로 계산됩니다.
  • 수수료는 진입 0.05%와 청산 0.05%, 왕복 합계 0.1%입니다.
  • 평단선은 차트 전체 폭의 실선, 수수료 포함 손익분기점은 회색 점선으로 표시됩니다.
  • 표시되는 청산가는 모의매매용 단순 계산값입니다.

3. 청산과 예약 청산

  • 부분 청산은 입력한 USDT만큼 포지션을 줄입니다.
  • 전체 청산은 해당 포지션을 종료하고 완료 기록으로 이동합니다.
  • 예약 청산은 금액을 입력하고 차트에서 청산 가격을 선택합니다.
  • 반대 방향으로 전환하려면 기존 포지션을 먼저 전량 청산해야 합니다.

4. 차트 사용

  • 초록색 B는 롱 진입, 분홍색 S는 숏 진입입니다.
  • 시간봉, 이동평균선, 볼린저밴드, 추세선, 수평선, 피보나치와 손익비 도구를 사용할 수 있습니다.
  • 내 표시 숨기기를 누르면 직접 만든 차트 표시와 진입 표식을 감출 수 있습니다.

5. 저장과 복구

  • 브라우저 저장소에 주 저장본과 교대 백업본이 자동 저장됩니다.
  • 백업 파일 연결로 독립 JSON 파일을 연결하면 매매 때마다 갱신됩니다.
  • 응급 백업 다운로드와 백업 복원으로 전체 기록을 이동할 수 있습니다.

이 프로그램은 연습용 모의매매 도구이며 실제 거래소 주문을 전송하지 않습니다.
